# PromptShield X — Adaptive, Trust-Aware AI Security Gateway

Built for **VORTEXA 3.0** (12-Hour Student Hackathon) at DY Patil College , Pimpri 

PromptShield is a cybersecurity platform designed to detect prompt injection attacks and potential data-exfiltration attempts in AI-powered applications. It combines rule-based pattern matching, machine-learning classification, intent-drift analysis, and policy-based decision-making to identify suspicious inputs. The system evaluates prompts for potential security risks and determines whether they should be allowed, blocked, or reviewed, depending on the implemented policies. It also includes an optional Gemini-based verification module for additional analysis.
